# 📊 Sales & Revenue Analysis Dashboard

## Overview
This Power BI dashboard analyzes sales and revenue using interactive visualizations and KPIs.

## Features
- Total Sales
- Total Revenue
- Total Profit
- Monthly Sales Trend
- Top Products
- Sales by Region
- Category-wise Analysis
- Payment Mode Analysis
- Interactive Filters & Slicers

## Tools Used
- Power BI
- Microsoft Excel
- CSV Dataset

## Dataset
The dataset contains 10,000 sales records with:
- Order Details
- Customer Information
- Product Information
- Region
- Revenue
- Profit
- Payment Mode
